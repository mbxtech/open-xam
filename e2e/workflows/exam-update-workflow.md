### Exam Update Workflow

This workflow describes the exam update workflow.

1. User enters the admin panel.
2. User sees the exam overview page.
3. User clicks on the exam update button of an existing exam.
4. User is redirected to the exam update page.
5. User sees all the questions of the exam.
6. User updates exam details.
7. User adds a new question to the exam.
8. User deletes an existing question from the exam.
9. A Dialog opens to confirm the action and ask for direct deletion.
10. User confirms the deletion.
11. User sees no errors
12. User is modifing an existing Question 

This workflow ensures that exam updates are performed efficiently and accurately.
